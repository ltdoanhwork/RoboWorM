# Training (post-training the world models)

The paper benchmarks **12 dense cells** (Table C1): 6 DreamGen, 3 DreamDojo, 3 Ctrl-World,
plus the 3-view Ctrl-World variants of bimanual / humanoid. Three cells use **released**
weights as is; the others were post-trained here. The recipes (steps, LR, batch, GPUs)
are in Table C3 of the paper and are regenerated by
`assets/scripts/make_finetune_config_table.py` from the `config.yaml` saved next to each
checkpoint. Checkpoint paths and sizes: [checkpoints/CHECKPOINTS.md](../../checkpoints/CHECKPOINTS.md).

"Source" = LeRobot data in `datasets/` ([../datasets/README.md](../datasets/README.md)).
"Prepare" = what turns it into the trainer's input. "Launcher" = the end-to-end training
script (it runs the prepare step unless told to skip it). Evidence = `dataset_dir` /
`dataset_path` / `ckpt_path` in the checkpoint's own `config.yaml` or launcher.

## DreamGen (Cosmos-Predict2 2B Video2World)

Env: `models/dreamgen/.venv`. Every `train_*.sh` runs prepare → T5-XXL embeddings →
`finetuning/dreamgen/launch.sh <experiment>` (all experiments, singleview and the 2x2-grid multiview ones, are defined in
`models/dreamgen/cosmos_predict2/configs/base/experiment/singleview.py`).
Checkpoints land in `checkpoints/finetuned/dreamgen/posttraining/{singleview,multiview}/<name>/`.

```bash
source models/dreamgen/.venv/bin/activate

# singleview (rows 9-11); SKIP_PREP=1 SKIP_T5=1 reuses the shipped datasets/*_16fps corpora
NPROC=4 bash finetuning/dreamgen/train_single_arm_static_16fps.sh
NPROC=4 bash finetuning/dreamgen/train_bimanual_16fps.sh
NPROC=8 bash finetuning/dreamgen/train_humanoid_16fps.sh

# multiview 2x2 grid (rows 7-8), training from the shipped *_seg16 corpora
SKIP_REENCODE=1 NPROC=4 bash finetuning/dreamgen/train_bimanual_multiview_grid_16fps.sh
SKIP_GRID=1 SKIP_SEGMENT=1 SKIP_T5=1 SKIP_REENCODE=1 NPROC=4 \
    bash finetuning/dreamgen/train_humanoid_multiview_grid_16fps.sh
```

Rebuilding the multiview corpora from scratch: humanoid — run
`train_humanoid_multiview_grid_16fps.sh` without the `SKIP_*` flags (it rebuilds grid →
segments → T5 → 16 fps). Bimanual — first run `finetuning/dreamgen/train_bimanual_multiview_grid.sh`
(grid + segments + T5, after `prepare_bimanual_multiview_grid_dreamgen.py`), then the
`_16fps` launcher without `SKIP_REENCODE`. T5 embeddings alone:
`bash finetuning/dreamgen/scripts/compute_t5_embeddings.sh`.

## DreamDojo (2B action-conditioned DiT)

Env: `models/DreamDojo/.venv`. `finetuning/dreamdojo/launch.sh <experiment>` runs
`torchrun -m scripts.train` inside `models/DreamDojo` with
`IMAGINAIRE_OUTPUT_ROOT=checkpoints/finetuned/dreamdojo` and the LAM checkpoint
`checkpoints/base/dreamdojo/LAM_400k.ckpt`.

```bash
NPROC=2 bash finetuning/dreamdojo/launch.sh dreamdojo_2b_480_640_single_arm_sv       # row 12
NPROC=2 bash finetuning/dreamdojo/launch.sh dreamdojo_2b_480_640_aloha               # row 13, stage 1
NPROC=2 bash finetuning/dreamdojo/launch.sh dreamdojo_2b_480_640_aloha_resume40k_bimanual_sv
NPROC=2 bash finetuning/dreamdojo/launch.sh dreamdojo_2b_480_640_aloha_resume70k_bimanual_sv   # 70k -> 100k
```

Each experiment writes `checkpoints/finetuned/dreamdojo/dreamdojo/exp_<group>/<name>/{checkpoints,config.yaml,video_logs}`.
The resume configs hard-code the `load_path` of the previous stage; if a resume fails on
training state, set `checkpoint.load_training_state: false` in the YAML (weights only).
The latent action model can be re-trained with
`python finetuning/dreamdojo/lam_project/main.py fit --config finetuning/dreamdojo/lam_project/config/lam_0.yaml`
(not needed for the paper; the released `LAM_400k.ckpt` is used).

## Ctrl-World (SVD 1.5B U-Net)

Env: `models/Ctrl-World/.venv`. Each launcher in `scripts/train/` does: (0) encode
LeRobot episodes into SVD latents + annotations under `models/Ctrl-World/dataset_example/<name>/`,
(1) build `models/Ctrl-World/dataset_meta_info/<name>/` (action/state stats), (2) run
`accelerate launch models/Ctrl-World/scripts/train_wm.py`. `SKIP_PREP=1 SKIP_META=1`
skips steps 0–1 on reruns. All paper variants run at 5 fps (`DOWN_SAMPLE=6`).

```bash
NPROC=4 bash scripts/train/run_bimanual_multiview_ctrlworld_train_5fps.sh        # row 2 (needs WARM_CKPT, see above)
NPROC=4 bash scripts/train/run_bimanual_multiview_ctrlworld_train_4view_grid.sh  # row 3
NPROC=4 bash scripts/train/run_humanoid_multiview_ctrlworld_train.sh             # row 4
NPROC=4 bash scripts/train/run_humanoid_multiview_ctrlworld_train_4view_grid.sh  # row 5
```

`finetuning/ctrlworld/` holds the trainer package mirrored from upstream (`train_ctrl_world.py`,
`config.py`, data loaders) and its own [README](../../finetuning/ctrlworld/README.md).
